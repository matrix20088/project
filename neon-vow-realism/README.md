# NEON VOW – realistic mobile rendering experiment

Not a finished game. True 3D third-person WebGL using the same real-time code inside the Android APK and screenshot runner.

Characters from third-party scanned, rigged, textured real humans distributed through the VideoIntoBlenderModel repository (see vendor licence terms and README there). Assets are downloaded and converted during CI only. Character originals are not committed to the repository.

Visual prototype tests:
- Two PBR detailed humanoid characters from real scans; real geometry, texture atlases.
- Environment with roads, signs, high-rise façades, towers, and moody lighting.
- Keyboard or touchscreen movement, attack, dash.
- Software WebGL screenshot captured from the same web frontend bundled into the APK.

**This is not a AAA-quality production game and cannot guarantee identical rendering on every phone.** It is intended for verifying art direction and Android feasibility.

Source: https://github.com/s0ck3t/VideoIntoBlenderModel
