# الهروب سوا 🚨

لعبة Android أصلية لشخصين عبر Bluetooth بدون حسابات أو إنترنت.

**طريقة اللعب**
1. نزّل نفس APK على الموبايلين.
2. شغّل Bluetooth واقرن الموبايلين مرة واحدة من إعدادات Android.
3. أحدكما يختار «أنشئ المهمة» والآخر «انضم للمهمة» ويختار جهاز الأول من القائمة.
4. في ممر الليزر أحدكما يرى الطريق الآمن بينما الثاني يختار الأبواب.
5. في غرفة الشفرة كل طرف معه نصف السر ويجب فك القفل سويًا.
6. في مرحلة الهروب اضغطا زرَّي التشغيل في نفس اللحظة.
7. تتبدل أدوار العميل والمخترق في المهمة التالية.

كل شيء يعمل محليًا على الجهازين عبر Bluetooth، دون خادم أو جمع بيانات.
