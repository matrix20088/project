# الهروب سوا 2.0 💘

تطبيق أندرويد لشخصين عبر Bluetooth، بدون إنترنت أو حسابات.

- 120 مهمة في 12 عالم، كل مهمة 4 تحديات، بإجمالي 480 جولة
- 12 نوع لعبة: أبواب الليزر، شفرة القفل، تسلسل الأسهم، الألغاز، التطابق، توقعات الآخر، الاعترافات، الهدايا، تمثيل الكلمات، ألعاب سرعة النقر، تحديات رومانسية، الهروب المتزامن
- 90 سؤال اختيار، 48 تحدي مرح ورومانسي، 24 لغزًا و24 بطاقة تمثيل
- درجة جرأة قابلة للاختيار مع موافقة الشريك قبل البدء
- تخطّي أي سؤال أو تحدي من غير خصم
- حفظ تقدم الموبايل المضيف محليًا

للتشغيل: ثبّت نفس APK على الجهازين، اقترن عبر إعدادات البلوتوث، افتح غرفة على جهاز، وانضم من الآخر ثم وافق على مستوى الجرأة.

قد تتطلب الترقية إزالة النسخة القديمة بسبب اختلاف مفتاح توقيع نسخة الاختبار.
